Kindle Web キャプチャ

ブラウザ版 Kindle（read.amazon.co.jp）からページ画像を取り出すための道具置き場

STEP 1：構造調査プローブ

本文がどの方式で描画されているかを調べるスクリプトです（画像や本文は保存しません）。結果の JSON を見て、キャプチャ本体の作り方を決めます。

プローブをインストール

Kindle Cloud Reader DOM Probe v1.0.0 ／ 要 Tampermonkey（Chrome / Edge）

STEP 2：キャプチャ本体

表示中のページ画像を PNG で保存し、自動でページ送りして連番保存するスクリプトです。プローブの調査結果（1枚画像・blob形式）に合わせて作ってあります。

キャプチャをインストール

Kindle Web Page Capture v1.0.0 ／ 要 Tampermonkey（Chrome / Edge）

使い方（キャプチャ）

  1. 上のボタンからキャプチャをインストールする
  2. read.amazon.co.jp で『幼女戦記』を開き、先頭ページを表示する
  3. 右下のパネルで 1ページだけテスト を押し、保存先フォルダを選ぶ
  4. 保存された page_0001.png を開いて、解像度と内容を確認する
  5. 問題なければ先頭ページに戻して 全ページ開始（最終ページで自動停止します）

プローブは調査が済んだので、もう使わなくて大丈夫です（Tampermonkey 側で無効化・削除して構いません）。
