Kindle Web キャプチャ

ブラウザ版 Kindle（read.amazon.co.jp）からページ画像を取り出すための道具置き場

STEP 1：構造調査プローブ

本文がどの方式で描画されているかを調べるスクリプトです（画像や本文は保存しません）。結果の JSON を見て、キャプチャ本体の作り方を決めます。

プローブをインストール

Kindle Cloud Reader DOM Probe v1.0.0 ／ 要 Tampermonkey（Chrome / Edge）

使い方

  1. 上のボタンからプローブをインストールする（Tampermonkey の確認画面で「インストール」）
  2. read.amazon.co.jp で『幼女戦記』を開く
  3. 右下の DOM調査 → 現在ページを調査 → JSONコピー
  4. 本文を手動で1ページめくって、もう一度 調査 → JSONコピー
  5. 2つの JSON を Muse のチャットに貼る

キャプチャ本体（自動ページ送り・連番保存）は、プローブの結果を見てからここに追加します。
